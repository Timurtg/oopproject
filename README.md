# Дышим чисто

## О проекте

«Дышим чисто» — проект веб-сервиса на Flask для просмотра и сравнения качества воздуха в российских городах. Пользователь сможет выбрать город, увидеть основные показатели загрязнения и посмотреть, как они меняются по времени. В дальнейшем сервис также поможет оценить, в какие часы условия лучше подходят для прогулки.

**Этап 2. Сбор данных.** Набор содержит сведения о качестве воздуха и погоде в 15 городах России за период с 1 октября 2025 года по 30 сентября 2026 года: 131 400 почасовых и 5 475 суточных записей.

## Файлы

| Файл | Содержание |
|---|---|
| [air_quality_dataset.xlsx](data/air_quality_dataset.xlsx) | Полный набор в одной книге: города, почасовые и суточные таблицы, словарь и отчёт о пропусках. |
| [cities.csv](data/cities.csv) | Города, регионы, координаты и часовые пояса. |
| [hourly.csv](data/hourly.csv) | Полная почасовая таблица. |
| [hourly_preview.csv](data/hourly_preview.csv) | Выборка за первые сутки периода по всем городам для просмотра в GitHub. |
| [daily.csv](data/daily.csv) | Полная таблица суточных агрегатов. |
| [daily_preview.csv](data/daily_preview.csv) | Выборка за первые семь дней периода по всем городам для просмотра в GitHub. |
| [data_dictionary.csv](data/data_dictionary.csv) | Назначение колонок и единицы измерения. |
| [data_quality_report.csv](data/data_quality_report.csv) | Число записей и доля пропусков по городам и показателям. |

Описание сбора и скрипт находятся в папке [`collection/`](collection/README.md).

В таблицах есть PM2.5, PM10, CO, NO₂, SO₂, O₃, индексы EAQI и US AQI, а также температура, влажность, осадки, ветер и давление. Суточная таблица включает агрегаты и признаки превышения рекомендаций ВОЗ для PM2.5 и PM10.

## Источники и ограничения

Качество воздуха: [Open-Meteo Air Quality API](https://air-quality-api.open-meteo.com/v1/air-quality), модель CAMS Global / Copernicus. Погода: [Open-Meteo Historical Weather API](https://archive-api.open-meteo.com/v1/archive), реанализ ERA5 / ECMWF / Copernicus. Данные Open-Meteo распространяются по лицензии [CC BY 4.0](https://open-meteo.com/en/licence).

Качество воздуха представлено модельными оценками на сетке, а не показаниями датчиков на улицах. Флаги превышения относятся к рекомендациям ВОЗ, а не к российским нормативам.
